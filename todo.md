### 2. ✅ Экспорт прогресса в PDF-отчёт
**Статус:** Реализовано
**Что сделано:**
- Установлены `jspdf` и `jspdf-autotable`

### 3. ✅ Service Worker для офлайн-работы
**Статус:** Реализовано
**Что сделано:**
- Настроен `next-pwa` с кэшированием статических ресурсов
- Service Worker (`public/sw.js`) с cache-first стратегией для статики
- Network-first для API маршрутов
- Офлайн-страница `/offline` с информацией о доступном контенте
- Индикатор офлайн-статуса в layout (компонент `OnlineStatusIndicator`)
- Кэширование: manifest, logo, все страницы и API
